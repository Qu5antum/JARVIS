# J.A.R.V.I.S

Локальный голосовой ассистент для Windows. J.A.R.V.I.S постоянно слушает микрофон, распознает русскую речь с помощью Whisper, выполняет команду и отвечает голосом через Edge TTS.

Проект умеет открывать сайты и приложения, управлять окнами, мышью, клавиатурой и громкостью, работать с медиа, ставить таймеры, считать простые выражения, проверять погоду и интернет, управлять процессами, скачивать видео и отправлять сообщения WhatsApp сохраненным контактам.

> Проект управляет компьютером напрямую. Перед первым запуском проверьте команды выключения, перезапуска, сна, закрытия процессов и автоматической отправки сообщений.

## Возможности

- распознавание команд на русском языке в реальном времени;
- голосовые ответы голосом `ru-RU-DmitryNeural`;
- открытие Chrome, сайтов и приложений Windows;
- управление клавиатурой, мышью, окнами, звуком и медиаплеером;
- таймер в отдельном потоке;
- погода через OpenWeatherMap;
- измерение скорости интернета через Speedtest;
- скачивание видео или аудио через `yt-dlp`;
- контакты в SQLite и отправка сообщений через WhatsApp Web.

## Требования

- Windows 10/11;
- Python 3.10+;
- рабочий микрофон и устройства вывода звука;
- Google Chrome для браузерных функций;
- подключение к интернету для Whisper-модели, TTS, погоды, перевода, Speedtest, загрузок и WhatsApp;
- FFmpeg для конвертации MP3 и объединения видео/аудио при скачивании;
- установленный Minecraft, Discord и Steam, если используются соответствующие команды.

Команды автоматизации мыши и клавиатуры выполняются через `pyautogui` и требуют разрешения на управление вводом. Некоторые действия могут зависеть от активного окна.

## Установка

Откройте PowerShell в корне проекта:

```powershell
py -3 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если PowerShell запрещает запуск скриптов, разрешение только для текущего процесса:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\venv\Scripts\Activate.ps1
```

Whisper-модель `small` будет загружена библиотекой `faster-whisper` при первом импорте. Это требует свободного места и доступа к интернету.

## Настройка `.env`

Создайте файл `.env` в корне проекта. Минимальный пример:

```dotenv
SAMPLE_RATE=16000
BLOCK_SIZE=1600
CHANNELS=1

WEATHER_API_KEY=ваш_ключ_openweathermap
MINECRAFT_DIRECTORY=C:\\Games\\Minecraft\\MinecraftLauncher.exe
DISCORD_DIRECTORY=Discord.exe
STEAM_DIRECTORY=steam.exe
```

`SAMPLE_RATE`, `BLOCK_SIZE` и `CHANNELS` имеют значения по умолчанию и обычно не требуют изменения. `WEATHER_API_KEY` нужен для погоды. Пути к Minecraft, Discord и Steam нужны только для запуска локальных приложений; Discord и Steam при отсутствии исполняемого файла открываются в браузере.

Не добавляйте `.env`, `database.db`, содержимое `downloads/` и личные данные в публичный репозиторий.

## Запуск

Запускайте из корня проекта с активированным виртуальным окружением:

```powershell
python -m src.main
```

После сообщения `Слушаю команды...` произнесите команду на русском языке. Для остановки нажмите `Ctrl+C`.

Основной цикл:

1. `sounddevice` получает моно-аудио с микрофона.
2. После накопления примерно 2,5 секунды аудио Whisper выполняет распознавание.
3. `JarvisMain.execute_command()` сравнивает текст с фразами команд.
4. Обработчик вызывает действие и, как правило, озвучивает результат.

Некоторые обработчики временно слушают микрофон повторно: поиск, карты, погода, таймер, перевод и WhatsApp. Скачивание и создание контакта дополнительно используют `input()` в терминале.

### Управление компьютером жестами

J.A.R.V.I.S поддерживает управление курсором и мышью с помощью камеры и MediaPipe Hand Landmarker. Камера отслеживает положение пальцев в реальном времени, а распознанные жесты преобразуются в действия мыши.

Для работы функции используется модель `hand_landmarker.task`.

Модель необходимо разместить в:

```text
models/
    hand_landmarker.task
```

Перед использованием убедитесь, что установлены зависимости:

```powershell
pip install mediapipe opencv-python numpy pyautogui
```

Управление жестами запускается отдельно и не блокирует основной голосовой цикл J.A.R.V.I.S.

**#### Основные жесты**

| Жест                                      | Действие                              |
| ----------------------------------------- | ------------------------------------- |
| Указательный палец                        | Перемещение курсора                   |
| Большой + указательный палец              | Левый клик                            |
| Большой + указательный палец с удержанием | Зажатие левой кнопки / перетаскивание |
| Мизинец + запястье                        | Правый клик                           |
| Указательный + средний пальцы             | Режим прокрутки                       |
| Указательный + средний пальцы вверх       | Прокрутка вверх                       |
| Указательный + средний пальцы вниз        | Прокрутка вниз                        |

**#### Перемещение курсора**

Указательный палец используется как виртуальный указатель.

J.A.R.V.I.S определяет координаты кончика указательного пальца и преобразует их в координаты экрана:

```text
Камера
   ↓
MediaPipe Hand Landmarker
   ↓
Координаты указательного пальца
   ↓
Преобразование координат
   ↓
Курсор Windows
```

Для уменьшения дрожания используется сглаживание движения курсора.

**#### Левый клик**

Соединение большого и указательного пальцев используется как левый клик.

```text
Большой палец
      ●
       \
        ●  ← указательный палец
```

При сближении пальцев J.A.R.V.I.S выполняет:

```text
pyautogui.click()
```

Между кликами используется cooldown, чтобы один жест не создавал большое количество кликов подряд.

**#### Перетаскивание**

Если большой и указательный пальцы удерживаются вместе, J.A.R.V.I.S зажимает левую кнопку мыши:

```text
Большой + указательный
        ↓
   mouseDown()
        ↓
Перемещение руки
        ↓
    mouseUp()
```

Это позволяет перетаскивать окна, файлы, элементы интерфейса и другие объекты.

**#### Правый клик**

Сближение мизинца и запястья используется для правого клика:

```text
Мизинец + запястье
        ↓
pyautogui.rightClick()
```

**#### Прокрутка**

Для прокрутки используются указательный и средний пальцы.

Когда пальцы находятся рядом, J.A.R.V.I.S переходит в режим scroll:

```text
Указательный + средний
          ↓
       Scroll
       ↙     ↘
    вверх    вниз
```

Движение вверх:

```text
↑
Прокрутка вверх
```

Движение вниз:

```text
↓
Прокрутка вниз
```

Прокрутка выполняется в отдельном потоке, поэтому движение страницы не блокирует обработку камеры.

**#### Архитектура**

Функция жестового управления построена следующим образом:

```text
J.A.R.V.I.S
     │
     ├── Whisper
     │
     ├── Command Detector
     │
     └── Computer Control
              │
              ├── OpenCV
              │     └── Camera
              │
              ├── MediaPipe Hand Landmarker
              │     └── Hand landmarks
              │
              └── HandTracker
                    ├── Cursor
                    ├── Left Click
                    ├── Drag & Drop
                    ├── Right Click
                    └── Scroll
```

Камера и обработка жестов работают в отдельном потоке. Это позволяет одновременно использовать голосовые команды J.A.R.V.I.S и управление компьютером рукой.

**#### Модель MediaPipe**

Используется современный MediaPipe Tasks API:

```python
HandLandmarker
HandLandmarkerOptions
RunningMode.VIDEO
```

Модель загружается из:

```text
models/hand_landmarker.task
```

Основные настройки:

```python
num_hands=1
min_hand_detection_confidence=0.5
min_hand_presence_confidence=0.5
min_tracking_confidence=0.5
```

**#### Безопасность**

Жестовое управление непосредственно отправляет события мыши в Windows через `pyautogui`.

Перед использованием рекомендуется проверить поведение:

* левого клика;
* правого клика;
* удержания кнопки;
* перетаскивания;
* прокрутки;
* остановки камеры.

Если камера или распознавание работают некорректно, необходимо остановить режим управления, чтобы избежать случайных действий мыши.

В дальнейшем система может быть расширена дополнительными жестами для клавиатуры и управления J.A.R.V.I.S:

```text
Открытая ладонь → пауза управления
Кулак → Escape
V-жест → Enter
Два пальца → переключение окон
Три пальца → копирование
Четыре пальца → вставка
Жест OK → подтверждение команды
```

## Известные ограничения текущей версии

- Диспетчер ищет подстроки, поэтому слишком длинная фраза может случайно попасть в другую команду. Важны порядок проверок и точные ключевые слова.
- Команды распознаются только на русском: в `faster-whisper` явно передается `language='ru'`.
- В коде нет отдельной голосовой команды выхода; для остановки используется `Ctrl+C`.
- `psutil` используется в `src/jarvis/proccess_manager.py`, но отсутствует в текущем `requirements.txt`. Если установка или импорт завершается ошибкой `ModuleNotFoundError: psutil`, установите `pip install psutil` и добавьте зависимость в requirements.
- Для системных команд в `command_detect.py` есть ветки, которые выполняют действие, но не всегда сразу возвращают `True` (таймер, вычисления, создание контакта и некоторые команды закрытия приложений). Это не мешает самому действию, но результат `execute_command()` может быть `False`.
- `webbrowser` регистрирует Chrome по фиксированному пути `C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe`; при нестандартной установке браузера его потребуется изменить.
- Перевод использует внешний сервис библиотеки `translate`, а TTS использует сетевой Edge TTS. Без интернета эти функции не работают.
- В `database/db.py` включен `echo=True`, поэтому SQL-запросы выводятся в консоль.
- Папка `downloads/` и база данных создаются/используются относительно текущей рабочей директории. Запускайте приложение из корня проекта.

## Диагностика

Если приложение не запускается:

1. Проверьте активность виртуального окружения: `where.exe python` должен указывать на `venv\\Scripts\\python.exe`.
2. Проверьте установку зависимостей: `pip install -r requirements.txt`.
3. Убедитесь, что микрофон и динамики видны Windows и не заняты другим приложением.
4. Проверьте наличие FFmpeg в `PATH`, если используется скачивание.
5. Для погоды проверьте `WEATHER_API_KEY` в `.env`.
6. Для Discord, Steam и Minecraft проверьте значения соответствующих путей.

Логи распознавания и ошибок выводятся в терминал. Полезные сообщения: `Loading Whisper model...`, `Слушаю команды...` и `Распознано: ...`.
